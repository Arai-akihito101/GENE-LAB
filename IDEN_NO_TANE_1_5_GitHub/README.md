## 公開（既存のCloudflare Pages + GitHub連携を利用）

1. ZIPを展開する。
2. **ZIPの中身すべて**（`index.html`、`learn/`、`sitemap.xml`、`robots.txt`、`favicon.svg`など）をGitHubリポジトリの最上位に上書きアップロードする。
3. GitHubでコミットし、Cloudflare Pagesでデプロイ成功を確認する。
4. 旧URLを変更せず、Search ConsoleのURL検査でトップ・`/learn/hw/`などを確認する。
5. Search Consoleのサイトマップ `/sitemap.xml` のステータスを後日確認する。検索順位は保証されない。

## 検索について

Google Searchに既に登録されているトップおよび記事URLは維持してください。**リネームのために新しいPagesプロジェクトを作成しないでください。**
検索向けの文言は、正しい教材内容を反映するものであり、キーワードの詰め込みやAI検索への特別な抜け道を意図していません。

## モデルの注意

花の色は教育用の不完全優性モデルです。実験の結果は乱数の影響を受けます。種分化テーマは集団分化を表しており、生殖隔離の成立を直接証明するものではありません。
