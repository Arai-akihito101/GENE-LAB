突然変異とは？

DNAの配列などが変化することで遺伝的変異が生じる現象です。進化の新しい変異の源になります。

DNAの塩基配列などが変わることを突然変異と呼びます。子孫に伝わる突然変異は集団内の遺伝的変異の源になります。

突然変異には有利なもの、不利なもの、中立に近いものがあり、目的を持って発生するわけではありません。

進化するために必要な突然変異は、環境に合わせて起こる？

特定の環境で役立つことを目的として突然変異が生じるわけではありません。新しく生じた変異のうち、環境に応じて繁殖成功に差が出るものに自然選択が働きます。

重要：突然変異は新しい対立遺伝子を生み、組換えは既存の対立遺伝子の組み合わせを変えます。この2つは区別しましょう。

次に試してみること

突然変異率を低い値と高い値で比べ、長期的に新しい変異がどの程度見つかるか観察しましょう。

しくみと具体例

この学習用モデルでは、1つの遺伝子座でAとaの間の変異が一定の確率で起こると仮定しています。

対称な突然変異率をμとすると、期待値では次世代のA頻度はp′=p(1−μ)+(1−p)μに従い、ほかの要因がなければ0.5に近づきます。

現実の突然変異は多様で、変異率や方向は一様ではありません。

シミュレーションで確かめる

読むだけでわかりにくいときは、条件を変えて観察しましょう。次の順番で試すと違いが見えやすくなります。

  1. 突然変異率を0%に設定して数十世代進める。
  2. 同じ初期条件で突然変異率を上げて進める。
  3. A頻度がどの方向に変化するか比較する。

実験を開いたら「＋1」「＋10」「＋50」で世代を進められます。花畑表示に対応するテーマでは表示も切り替えられます。

モデルの注意点：対称なA↔a変異を使う簡略モデルです。実際のDNAの塩基変化を個別に追跡するものではありません。

よくある疑問

突然変異が起きれば進化する？

遺伝しうる変異が集団に現れれば、頻度が変化する可能性が生まれます。ただしすべての変異が集団に残るわけではありません。

環境に必要な突然変異が狙って起こる？

突然変異が生じる方向は、一般に生物が必要とする適応に合わせて決まるわけではありません。自然選択が後から変異の広まりやすさに作用します。
